# Coding House Website

Official website for **Coding House Software Pvt. Ltd.** — Premier software engineering studio based in Surat, Gujarat, India.

## Tech Stack
- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS** + **Framer Motion**
- **Lucide Icons**
- **SEO Optimized** (Schema.org JSON-LD, Sitemap.xml, Robots.txt)

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview
```bash
npm run preview
```
